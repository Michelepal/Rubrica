# Storico prompt del progetto

Questo file raccoglie i prompt forniti durante la definizione dei requisiti del progetto rubrica full stack.

## Prompt 1

```text
Crea la base di un progetto full stack di una rubrica: la parte grafica deve essere fatta con Angular e il backend deve essere un progetto gradle +springboot che deve contenere una procedura di login e il servizio per un db locale che contenga i dati della rubrica. Prima di procedere, fai un analisi dei requisiti dell'attività e poi elenca i passaggi da effettuare.
```

## Prompt 2

```text
Fai un analisi dei dati necessari per il funzionamento della rubrica e progetta il db e le relazioni tra tabelle di conseguenza.
```

## Prompt 3

```text
La compilazione dei dati lato front end andranno sanificati e validati attraverso validator specifici. Valuta anche di inserire controlli anche lato backend e nel db,
```

## Prompt 4

```text
Il login andrà gestito con spring seecurity  e springboot. dal path base localhost:xxx:xx/ dovrà reindirizzare al path /login e in caso di login andato a buon fine rimandare alla home dell'app Angular, oppure ad una pagina di errore
```

## Prompt 5

```text

```
